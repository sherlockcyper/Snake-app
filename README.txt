لعبة الثعبان — حزمة التثبيت على أندرويد
=========================================

محتويات المجلد:
  index.html            اللعبة كاملة
  manifest.webmanifest  بيانات التطبيق (الاسم والأيقونة وملء الشاشة بالوضع العمودي)
  sw.js                 يخزّن اللعبة بعد أول تشغيل لتعمل بلا إنترنت
  icons/                أيقونات التطبيق

ملاحظة مهمة: ملف APK نفسه يحتاج إلى أدوات أندرويد وتوقيع رقمي، ولا يمكن بناؤه داخل المحادثة.
هذه الحزمة جاهزة لأسهل طريقتين للحصول عليه:

------------------------------------------------------------
الطريقة 1: تثبيت مباشر كتطبيق (بدون ملف APK) — الأسرع
------------------------------------------------------------
1) ارفع هذا المجلد كاملًا إلى استضافة مجانية بعنوان https، مثل:
     - Netlify Drop:  app.netlify.com/drop   (اسحب المجلد إلى الصفحة)
     - GitHub Pages أو Cloudflare Pages
2) افتح الرابط في متصفح Chrome على الهاتف.
3) من قائمة المتصفح (⋮) اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
4) سيظهر بأيقونته ويعمل بملء الشاشة. ويعمل بعد ذلك بدون إنترنت.

------------------------------------------------------------
الطريقة 2: ملف APK حقيقي — عبر PWABuilder (مجاني، دون برمجة)
------------------------------------------------------------
1) استضف المجلد كما في الطريقة 1 واحصل على الرابط.
2) افتح pwabuilder.com وألصق رابط اللعبة ثم ابدأ الفحص.
3) اختر «Package for stores» ثم «Android» ونزّل الحزمة.
4) في الملف المضغوط الناتج ستجد ملف APK للتثبيت المباشر، وملف AAB لمتجر Google Play،
   ومفتاح التوقيع: احتفظ به في مكان آمن لأنك ستحتاجه لتحديث التطبيق لاحقًا.
5) انقل APK إلى الهاتف وثبّته (يجب السماح بالتثبيت من مصدر غير معروف لمرة واحدة).
(واجهة الموقع قد تتغير قليلًا مع الوقت، لكن الخطوات العامة هي نفسها.)

------------------------------------------------------------
الطريقة 3: تطبيق يعمل بلا إنترنت من أول مرة (يتطلب حاسوبًا)
------------------------------------------------------------
اللعبة تحمّل مكتبة three.js من الإنترنت (ثم تُخزَّن للتشغيل دون اتصال).
لتضمينها داخل التطبيق نفسه:
1) نزّل الملف التالي واحفظه بجانب index.html باسم three.min.js:
     https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
2) في index.html غيّر سطر الاستدعاء إلى:  <script src="three.min.js"></script>
3) ثبّت Node.js وAndroid Studio ثم نفّذ في مجلد جديد:
     npm init -y
     npm i @capacitor/core @capacitor/cli @capacitor/android
     npx cap init "لعبة الثعبان" com.example.snake --web-dir www
     (انسخ محتويات هذا المجلد إلى مجلد www)
     npx cap add android
     npx cap sync
     npx cap open android
4) في Android Studio: Build ← Build Bundle(s) / APK(s) ← Build APK(s).
